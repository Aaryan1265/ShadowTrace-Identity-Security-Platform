Send authentication telemetry to ShadowTrace

Applications, identity providers, or internal services can POST authentication events to /api/events. Set SHADOWTRACE_API_KEY in a real deployment to require the X-API-Key header. 

curl -X POST http://localhost:8000/api/events \
  -H "Content-Type: application/json" \
  -H "X-API-Key: your-key" \
  -d '{
    "user_id": "alice",
    "timestamp": "2026-08-24T14:15:00Z",
    "ip_address": "192.0.2.10",
    "country": "Canada",
    "city": "Toronto",
    "device_id": "alice-laptop",
    "success": true,
    "source": "my-application"
  }'
